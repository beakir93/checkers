# Русские шашки

Браузерная игра в русские шашки: вдвоём за одним устройством или против компьютера.

**Играть:** https://beakir93.github.io/checkers/

## Возможности

- Игра против компьютера (три уровня сложности) или вдвоём.
- Ход кликом или перетаскиванием, подсказки возможных ходов.
- История ходов в нотации (`c3-d4`, `e3:g5:e7`), отмена хода, переворот доски.
- Партия сохраняется в браузере и переживает перезагрузку страницы.
- Светлая и тёмная тема, адаптивная вёрстка для телефона.

## Правила

- Доска 8×8, по 12 шашек, первыми ходят белые.
- Бить обязательно. Простая шашка бьёт вперёд и назад.
- Серию взятий нужно довести до конца, но выбрать можно любую ветку, не обязательно самую длинную.
- Дойдя до последней горизонтали, шашка становится дамкой, в том числе посреди взятия, и продолжает бить уже как дамка.
- Дамка ходит и бьёт на любое расстояние по диагонали. Если после взятия дамка может бить дальше, она обязана встать на поле, откуда это возможно.
- Турецкий удар: сбитые шашки снимаются с доски только после окончания хода, и перепрыгнуть их второй раз нельзя.
- Проигрывает тот, у кого нет шашек или ходов. Ничья объявляется при троекратном повторении позиции или если 15 ходов подряд обе стороны ходили только дамками без взятий.

## Запуск локально

```bash
npm install
npm run dev     # сервер разработки
npm test        # тесты правил и бота
npm run build   # сборка в dist/
```

## Устройство

- `src/rules.ts` — генерация ходов и правила.
- `src/game.ts` — состояние партии, конец игры, ничьи.
- `src/ai.ts` — бот: минимакс с альфа-бета отсечением и итеративным углублением. Работает в Web Worker (`src/ai.worker.ts`), чтобы не подвешивать интерфейс.
- `src/main.ts` — отрисовка доски и управление.

Деплой на GitHub Pages идёт автоматически при каждом пуше в `main` (`.github/workflows/deploy.yml`).
